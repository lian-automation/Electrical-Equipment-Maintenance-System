# Electrical-Equipment-Maintenance-Simulation（工厂电气设备全流程维护体系文档包 + 故障场景推演材料）

> 一套面向离散制造工厂的电气设备维保体系文档包（教学/示例用途）：**点检标准化 → 保养计划化 → 故障案例化 → 应急程序化 → 备件数据化 → 培训体系化 → 制度文件化**。

> **项目定位声明（这是什么 / 不是什么）**
> - **是什么**：电气设备维护管理体系**文档包** + 故障场景**推演材料**（教学/示例用途）——全套 Markdown 文档与示例数据表，覆盖点检、保养、故障库、应急、备件、培训、制度七大模块；
> - **不是什么**：**不含任何仿真软件、可执行代码或交互系统**。项目名沿用 `Simulation`，取"用示例数据与演练脚本对维保体系进行**模拟推演**"之义（演练方案即推演脚本、复盘样例即推演记录），**不代表存在数字孪生或仿真程序**，实际交付物为文档体系包；
> - 文中设备型号、供应商、数量、日期、人名与统计数字均为**示例数据**，不构成真实运行数据；使用前请结合本厂实际与现行标准校核修订。

## 一、项目简介

本项目模拟一家中型制造工厂（约 300 台/套电气设备，涵盖高低压配电柜、三相异步电机、变频器、PLC 控制柜、伺服驱动系统、现场传感器与工业通讯网络）的电气设备全流程维护体系。项目借鉴核电行业成熟的**预防性维修（PM）、两票三制、经验反馈（OPEX）、纵深防御**等管理思想，将工厂电气维保工作拆解为可执行、可量化、可追溯的模块：日/周点检标准、年度保养计划、50 个典型故障案例库、《电气设备应急预案》与电机烧毁应急演练方案（附复盘报告样例）、备件安全库存管理、新员工电气安全培训，以及四份基础管理制度汇编与台账/票样示例。

传统的工厂电气维保普遍存在"三无"问题：**点检无标准**（凭老师傅经验，看不懂什么叫"正常"）、**故障无沉淀**（同一个故障反复发生，每次都从头排查）、**应急无程序**（出事靠吼、抢修靠抢、复盘靠忘）。本项目的目标就是把这三块短板逐一补齐：

1. **点检有标准**——每台设备的每个检查项都有明确量化阈值（如电机三相电流不平衡度 ≤10%、PLC 柜温 ≤40℃、接地电阻 ≤4Ω），新员工照表即可点检；
2. **故障有沉淀**——50 个高频故障按"现象→排查步骤→根本原因→处理方案→预防措施"五段式入库，重复故障按"设备类型+现象关键词"快速检索、平均修复时间（MTTR）缩短；
3. **应急有程序**——《电气设备应急预案》明确组织机构、响应分级与处置恢复程序；从报警、抢修、备件调用到复盘报告全流程脚本化，演练有本可依、复盘有样可循。

### 核心业务流程

维保业务主流程为：**点检 → 异常上报 → 故障诊断 → 维修 → 验收归档**，形成闭环管理：

```mermaid
flowchart TD
    A[日常点检<br/>日点检 / 周点检 / 专项点检] --> B{发现异常?}
    B -- 否 --> A
    B -- 是 --> C[异常上报<br/>MES 提交维修工单 / 班组群即时上报]
    C --> D[故障诊断<br/>检索故障库案例 + 万用表/示波器/热像仪检测]
    D --> E{能否立即修复?}
    E -- 否 --> F[制定检修方案<br/>办理检修作业票 / 停送电操作票 / 领用备件]
    E -- 是 --> G[现场维修处理]
    F --> G
    G --> H[试车验收<br/>操作工 - 班组长 - 设备工程师三级验收]
    H --> I[归档与经验反馈<br/>案例入库 / 更新点检表 / 备件消耗登记]
    I --> A
```

> 备件管理贯穿维修环节：备件出库后库存低于安全线，由库管员**当日发起采购申请（PR）**触发补货；紧急抢修走绿色通道（先发货、后补手续），详见[《备件安全库存表》](备件管理/备件安全库存表.md)。

## 四、关键维保指标（KPI）

| 指标 | 定义 | 目标值 |
|---|---|---|
| 点检执行率 | 实际点检班次 / 计划点检班次 | ≥ 95% |
| MTTR | 平均故障修复时间 | ≤ 2 h |
| MTBF | 平均无故障运行时间 | ≥ 720 h |
| 故障重复率 | 30 天内同一设备同一故障再发比例 | ≤ 3% |
| 备件满足率 | 维修领用时备件可用比例 | ≥ 98% |
| 演练完成率 | 年度应急演练计划完成比例 | 100% |

> **统计口径**（与[《台账与票样/MTTR与MTBF月度统计示例.md》](台账与票样/MTTR与MTBF月度统计示例.md)一致，示例数据）：
> - **MTTR** = Σ（每次故障从发现报障至试车验收合格的历时）/ 故障次数，数据取自 MES 工单与 MTTR 月度统计；
> - **MTBF** = 统计周期内设备总运行台时 / 故障次数；
> - **故障重复率** = 30 天内同一设备同一故障再发次数 / 同期故障总数；
> - **备件满足率** = 领用时备件可用的工单数 / 领用工单总数；
> - **点检执行率**分母按计划点检班次计，覆盖口径（操作工岗位点检 + 电气巡检抽核）见[《日点检表》](点检标准/日点检表.md)头部说明。

## 五、使用方法

1. 新工厂/新车间投运时，先按《设备台账管理制度》（见[《电气设备管理制度汇编》](制度文件/电气设备管理制度汇编.md)）与[《设备台账示例》](台账与票样/设备台账示例.md)建立台账，再按设备类型套用[《日点检表》](点检标准/日点检表.md)[《周点检表》](点检标准/周点检表.md)模板，记录填写参考[《点检记录台账示例》](台账与票样/点检记录台账示例.md)；
2. 按[《年度保养计划》](保养计划/年度保养计划.md)排定全年保养与预防性更换任务，录入 MES 生成周期性工单；
3. 每次故障处理后，按五段式格式将案例追加进[《故障案例库》](故障库/50个故障案例库.md)（先查其"快速检索索引"），并回头修订点检表与保养周期；
4. 每半年组织 1 次应急演练、全年不少于 2 次（上半年按[《电机烧毁应急演练方案》](应急演练/电机烧毁应急演练方案.md)实战演练，下半年结合秋检按[《电气设备应急预案》](应急演练/电气设备应急预案.md)选定全厂失电、变压器故障等场景），用[《演练复盘报告样例》](应急演练/演练复盘报告样例1-电机烧毁.md)模板闭环；
5. 按[《备件安全库存表》](备件管理/备件安全库存表.md)执行"低于安全线即当日补货"，按[《新员工电气安全培训大纲》](培训材料/新员工电气安全培训大纲.md)（含[《电气安全红线十条》](制度文件/电气安全红线十条.md)解读）完成新员工取证上岗。
