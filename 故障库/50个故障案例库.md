# 50 个工厂常见电气故障案例库

> **使用说明**：本案例库按"现象→排查步骤→根本原因→处理方案→预防措施"五段式编写，覆盖**电机、PLC、伺服、通讯、传感器**五大类各 10 例。
> **检索方式**：按设备类型 + 故障现象关键词检索；维修完成后如有新情况，请在案例下方追加"补充记录"。
> **闭环规则**：每次真实故障处理完，若案例库无匹配案例，按本格式新增入库并编号；预防措施需同步落到点检表或保养计划中，才算闭环。

# 第一类：电机故障（案例 01—10）

### 案例 01｜电机启动即跳闸
- **现象**：按下启动按钮，主回路断路器立即跳闸，电机未转动或刚转动即停。
- **排查步骤**：①测回路三相电压是否缺相、偏低；②停电测电机绕组直流电阻，三相不平衡应 <5%；③打开接线盒检查有无烧焦、进水痕迹；④500V 兆欧表测绕组对地绝缘；⑤核对断路器整定值与电机额定电流是否匹配。
- **根本原因**：接线盒密封失效进水受潮，绕组相间短路。
- **处理方案**：拆除电机，绕组短路点修复并浸漆烘干，绝缘 ≥1MΩ 后回装；重做接线盒密封与电缆防水弯。
- **预防措施**：接线盒密封纳入日检；雨季前对室外/冲洗区电机专项摇绝缘。

### 案例 02｜电机缺相运行
- **现象**：电机"嗡嗡"声沉闷、转速下降、机身快速发热，钳形表测三相电流明显不平衡（一相接近零）。
- **排查步骤**：①测三相电流确认缺相相别；②检查熔断器、断路器该相；③停电检查接触器三副触点（重点：静触点烧蚀、弹簧压力）；④测电机接线盒端子三相电压；⑤检查电缆中间接头。
- **根本原因**：接触器一相触点烧蚀氧化，接触电阻过大近乎断路。
- **处理方案**：更换接触器；电机过热后冷却，摇测绝缘合格方可再投运；加装/校验缺相保护。
- **预防措施**：接触器触点纳入周检；大功率电机回路加装断相与不平衡保护继电器。

### 案例 03｜三相电流不平衡
- **现象**：运行电流三相不平衡度 >10%，电机温升偏高，伴轻微电磁噪声。
- **排查步骤**：①钳形表分别测 U/V/W 电流；②测电源侧三相电压不平衡度（应 <2%）；③停电测绕组直流电阻排除匝间问题；④红外测温检查各接线端子。
- **根本原因**：电源电压本身不平衡，叠加端子松动发热氧化。
- **处理方案**：紧固并处理氧化端子，涂导电膏；电压不平衡 >2% 时联系供电部门/检查变压器分接头。
- **预防措施**：端子紧固与红外测温纳入周检；电流不平衡度纳入日检记录。

### 案例 04｜电机轴承温度过高
- **现象**：轴承座温度 >80℃ 且持续上升，听诊有"沙沙"或"咔哒"声，润滑脂变稀外溢。
- **排查步骤**：①红外测温定位驱动端/非驱动端；②听诊棒判断异音性质（缺脂"吱吱"/疲劳"咔哒"）；③检查补脂记录与脂型号是否混用；④检查联轴器对中与皮带张紧力；⑤盘车检查预紧力。
- **根本原因**：补脂过量（超过轴承腔 2/3）+ 联轴器不对中。
- **处理方案**：清洗轴承室更换润滑脂（**换脂初次填充**按《年度保养计划》周期表第 1 项注①口径：轴承及轴承室自由空间的 1/2～2/3；此后运行中补脂按自由空间 1/3～1/2 执行），激光找正对中偏差 ≤0.05mm；轴承损伤则更换。
- **预防措施**：按 2000h 定量补脂并做记录；年度保养做激光对中复校。

### 案例 05｜电机振动超标
- **现象**：电机机身振动速度 >4.5mm/s，地脚处手感明显，联接件有异响。
- **排查步骤**：①振动笔分别测驱动端、非驱动端、地脚三处并记录频谱特征；②检查地脚螺栓与垫片；③脱开负载空载运行，判断振源在电机还是负载；④检查皮带轮/联轴器是否松动、平衡块脱落。
- **根本原因**：地脚螺栓松动叠加轴承磨损，引起 1 倍频与轴承特征频率振动。
- **处理方案**：紧固地脚螺栓并重新调平垫实；更换轴承并做转子动平衡校验。
- **预防措施**：振动纳入日检手感+月度数值测量，建立振动趋势台账。

### 案例 06｜绕组绝缘电阻偏低
- **现象**：周检摇测绝缘电阻 <0.5MΩ（500V 兆欧表），电机外观有凝露。
- **排查步骤**：①解开电缆分别摇电机侧、电缆侧，定位低绝缘段；②打开接线盒检查是否受潮、积水；③核对停用时长；④擦拭瓷壳与接线板污湿后复测。
- **根本原因**：车间湿热+电机停用一个月，绕组受潮凝露。
- **处理方案**：热风（或碘钨灯，控温 ≤80℃）烘干至绝缘 ≥1MΩ 再投运；更换接线盒干燥剂。
- **预防措施**：停用电机每周空载运行 30min 驱潮；雨季前专项摇测。

### 案例 07｜星三角启动切换瞬间跳闸
- **现象**：星形降压启动正常，切换至三角运行瞬间断路器跳闸。
- **排查步骤**：①检查星三角切换时间继电器整定（一般 8～10s）；②检查星点接触器与主接触器的电气/机械互锁；③录波或钳形表观察切换瞬间电流冲击；④核对绕组六个端子 U1U2/V1V2/W1W2 接线。
- **根本原因**：切换时间整定过短（3s），电机转速未建立，切换电流冲击大；互锁触点粘连引起相间短路。
- **处理方案**：重新整定切换时间，更换粘连的接触器，空载模拟切换 3 次验证。
- **预防措施**：时间继电器整定值纳入调试档案；互锁触点纳入年检功能试验。

### 案例 08｜变频电机轴承频繁损坏（电蚀）
- **现象**：变频驱动电机半年内两次轴承损坏，解体检查滚道呈"搓板纹"暗色条纹。
- **排查步骤**：①查变频器载波频率设置是否过高；②核对电机是否配置绝缘轴承或轴接地电刷；③检查电机电缆屏蔽层是否两端可靠接地；④示波器/轴电压表测轴电压。
- **根本原因**：变频器共模电压产生轴电流，放电电蚀轴承滚道。
- **处理方案**：非驱动端更换绝缘轴承，驱动端加装轴接地碳刷；动力电缆屏蔽层 360° 环接两端接地；适当降低载波频率。
- **预防措施**：变频电机采购规范中明确"绝缘轴承+接地碳刷"；改造后测轴电压验证 <0.5V。

### 案例 09｜电机接线盒端子烧黑
- **现象**：日检闻到焦糊味，接线盒内一相端子绝缘碳化发黑，红外测温该点明显高于其他相。
- **排查步骤**：①红外测温确认发热点；②停电打开接线盒检查端子氧化与压接情况；③微欧计/双臂电桥测接触电阻；④核对线鼻子规格与螺栓等级。
- **根本原因**：冷压端子与螺栓规格不匹配，压接不实，长期发热氧化恶性循环。
- **处理方案**：重新压接匹配规格线鼻子，接触面涂导电膏，力矩扳手按规定力矩紧固；碳化严重的电缆截断重做。
- **预防措施**：端子红外测温纳入周检；检修后一律力矩紧固并做标记线。

### 案例 10｜绕线式电机集电环冒火花
- **现象**：绕线式电机集电环表面冒火花，碳刷磨损快，刷握发热。
- **排查步骤**：①测碳刷弹簧压力（应为 15～25kPa 且各刷均匀）；②核对碳刷牌号是否与原厂一致、长度是否 <1/2；③检查集电环表面粗糙度、椭圆度与烧蚀麻点；④检查刷握与集电环间隙是否偏斜。
- **根本原因**：碳刷压力不均导致各刷电流分布不均，个别碳刷过流起弧烧蚀集电环。
- **处理方案**：上车床光刀集电环表面（Ra1.6），更换同牌号整套碳刷，调整各刷压力均匀。
- **预防措施**：月检碳刷长度与压力；保持集电环与刷握清洁无油污。

# 第二类：PLC 故障（案例 11—20）

### 案例 11｜CPU 报 SF/ERR 红灯停机
- **现象**：PLC CPU 面板 SF/ERR 红灯亮，设备联锁停机，HMI 报"PLC 故障"。
- **排查步骤**：①编程软件连 CPU 读诊断缓冲区，确定首故障；②逐个检查模块/从站是否有红色故障标识；③检查 CPU 风扇与柜内温度；④检查存储卡是否松动/报写保护；⑤测 CPU 供电电压。
- **根本原因**：某 ET200 远程站 24V 电源失电，CPU 报总线访问错误触发停机。
- **处理方案**：恢复远程站供电（更换其开关电源），CPU 清除故障复位；远程站电源改由 UPS 供电。
- **预防措施**：远程站电源接入 UPS；总线掉站诊断报警上传 MES 提前预警。

### 案例 12｜PLC 数字量输出点不动作
- **现象**：程序中输出线圈已置位，但现场接触器不吸合。
- **排查步骤**：①万用表测输出端子对公共端电压（应有 24V/220V）；②检查输出组公共端 COM 及组熔丝；③在端子排短接验证外部执行回路好坏；④编程软件强制输出 ON，观察通道灯与电压；⑤判断是否继电器型输出触点失效。
- **根本原因**：继电器输出板该点触点经长期动作后烧蚀粘连-烧断，失效。
- **处理方案**：更换输出模块（或备用通道改点并修改地址映射）；高动作频率回路改"晶体管输出+中间继电器"隔离。
- **预防措施**：高频动作负载一律经中间继电器；备一块同型号输出模块。

### 案例 13｜PLC 数字量输入信号丢失
- **现象**：现场限位开关动作，但 PLC 对应输入指示灯不亮，程序读不到信号。
- **排查步骤**：①在现场端短接信号线与 0V，看输入灯是否亮（区分现场/柜内）；②测输入通道端子电压（应≈24V）；③二线制传感器检查剩余电流是否使输入处于临界；④测电缆通断（重点拖链段）；⑤把信号线换到备用通道交叉验证。
- **根本原因**：拖链内电缆长期弯折疲劳断芯。
- **处理方案**：更换高柔性拖链电缆并重新穿管固定；预留备用芯。
- **预防措施**：拖链电缆按弯曲寿命选型（≥500 万次）；布线预留 20% 备芯。

### 案例 14｜PLC 掉电后数据丢失
- **现象**：车间停电再来电，PLC 保持型数据（配方、计件数）清零。
- **排查步骤**：①检查 CPU 电池状态位/告警历史；②上电状态测电池电压（<2.8V 判失效）；③核对停电时长是否超出电容+电池保持能力；④比对最近程序与数据备份时间。
- **根本原因**：CPU 锂电池（S7-300 等带电池机型）到寿命（3 年）电压不足，停电后保持数据丢失。
- **处理方案**：在 CPU 通电状态下更换同型电池；从最近备份恢复配方数据。
- **预防措施**：电池列入预防性更换周期表第 3 项（3 年强换，仅 S7-300 等带电池机型；S7-1200 无用户可更换的后备电池，以按月异机备份为数据安全手段）；程序与配方每月异机备份。

### 案例 15｜模拟量输入漂移跳变
- **现象**：AI 通道读数无规律跳变（如 4～20mA 信号在 30%～90% 间波动）。
- **排查步骤**：①信号发生器分别注入 4/8/12/16/20mA 标准信号看读数；②检查信号电缆屏蔽层接地方式（应单端接地）；③检查信号线与动力电缆是否同槽敷设；④检查变送器供电纹波；⑤与完好通道对调模块接线定位漂移源。
- **根本原因**：屏蔽层两端接地形成地环流，且信号线与变频器输出电缆同槽，耦合干扰。
- **处理方案**：屏蔽层改单端（柜侧）接地；信号电缆移出动力桥架，间距 ≥300mm。
- **预防措施**：施工规范规定信号/动力分层敷设；AI 信号纳入趋势监控自动报警。

### 案例 16｜PLC 扫描周期过长
- **现象**：设备动作迟缓、急停响应慢，偶发看门狗超时错误。
- **排查步骤**：①在线监视当前/最大扫描时间；②分段使能程序块，定位耗时块；③检查主循环中是否有大数据量 DB 拷贝、字符串处理；④检查通讯任务是否同步调用（如 Modbus 库阻塞）。
- **根本原因**：技术改造新增程序整段放在主循环同步执行，单周期达 500ms 以上。
- **处理方案**：长任务拆分为分时步进执行或移至低优先级循环；通讯改异步调用；重新整定看门狗时间并留 50% 裕量。
- **预防措施**：程序修改走变更流程+性能测试；扫描时间纳入 HMI 在线监视。

### 案例 17｜扩展模块无法识别
- **现象**：上电后 CPU 报 I/O 访问错误，一排扩展模块全部无响应。
- **排查步骤**：①断电重插总线连接器并检查到位卡扣；②测背板总线供电电压；③逐级单模块上电定位故障模块；④核对硬件组态与实际模块订货号、地址是否一致。
- **根本原因**：控制柜顶渗水滴入总线插槽，插槽短路烧蚀连接器。
- **处理方案**：干燥处理、更换损坏模块与总线连接器；柜顶加装防漏挡板并封堵穿线孔。
- **预防措施**：控制柜防护等级（IP54）年检；柜顶严禁开孔走线。

### 案例 18｜输出公共端熔丝熔断整排失效
- **现象**：一组 DO 通道指示灯正常但外部执行元件全部不动作。
- **排查步骤**：①测该组 COM 端电压（应为 0V 或 24V 视类型）；②检查输出分组熔丝/微型断路器；③分路断开后摇测外部回路绝缘，定位短路支路；④检查执行元件（电磁阀线圈）电阻。
- **根本原因**：一只电磁阀线圈匝间短路，大电流拉断该组公共端熔丝。
- **处理方案**：更换电磁阀与同规格熔丝，逐路恢复验证。
- **预防措施**：每组输出分路加熔丝保护；电磁阀线圈并联压敏电阻吸收浪涌。

### 案例 19｜PLC 柜高温频繁重启
- **现象**：夏季午后 CPU 反复重启，故障时间集中在 14:00—16:00。
- **排查步骤**：①记录柜内温度（点检温度计/测温枪）；②检查柜顶风扇运转与滤网堵塞；③检查柜用空调/热交换器制冷效果；④检查 CPU 模块风扇；⑤核对负载率与散热冗余。
- **根本原因**：滤网堵塞+一只风扇烧毁，柜内温度 >55℃ 触发 CPU 过温复位。
- **处理方案**：更换风扇、清洗滤网、加装柜用工业空调，柜温告警（>45℃）上传 MES。
- **预防措施**：柜温纳入日检（≤40℃）；滤网周清洗、风扇按 2 年周期预防更换。

### 案例 20｜变频器运行时 PLC 输入误动作
- **现象**：变频器一启动，PLC 部分输入点误动作、高速计数乱跳。
- **排查步骤**：①示波器观察 24V 电源纹波（应 <5%）；②检查变频器输入侧是否装交流电抗器/EMI 滤波器；③检查接地系统连接与接地电阻；④检查双线制传感器剩余电流；⑤临时停变频器验证相关性。
- **根本原因**：变频器未装进线电抗器，开关谐波经电源母线耦合进入 24V 系统与输入回路。
- **处理方案**：加装进线电抗器与 EMI 滤波器；24V 电源加装隔离型电源；双线传感器改三线制。
- **预防措施**：变频器改造必须配套电抗器；接地电阻按周点检轮换覆盖制抽测（≤4Ω，每周抽测 20%、每月全覆盖）。

# 第三类：伺服系统故障（案例 21—30）

### 案例 21｜伺服使能即报过流
- **现象**：伺服驱动器一使能就跳过流报警（如 OC / F30001 / A.400 类代码）。
- **排查步骤**：①记录报警代码与历史频次；②拆除电机动力线后再使能驱动器——若不报警则故障在电机/电缆侧；③摇测电机绝缘及相间电阻；④检查动力电缆绝缘破皮（重点拖链入口、穿板处）；⑤盘车检查机械是否堵转。
- **根本原因**：电机动力电缆被防护罩铁皮割破，对地短路。
- **处理方案**：更换动力电缆并加装护套/护口，重新设置增益与惯量比后试机。
- **预防措施**：电缆穿金属件处一律加护口；日检目视电缆外观。

### 案例 22｜减速时直流母线过压
- **现象**：大惯量负载快速减速时报母线过压（OV / A.320 类）。
- **排查步骤**：①驱动器监视母线电压曲线，确认发生在减速段；②检查减速时间与减速曲线设置；③检查内置/外置制动电阻阻值、接线及回路熔丝/接触器；④测进线电压是否偏高（>420V）。
- **根本原因**：制动单元回路接触器触点烧断，再生能量无处泄放，母线泵升过压。
- **处理方案**：更换制动回路器件；减速时间由 0.2s 放宽至 0.5s；必要时更换更大功率制动电阻。
- **预防措施**：母线电压纳入趋势监视；制动电阻温度纳入点检。

### 案例 23｜伺服报欠压
- **现象**：伺服运行中报欠压（UV / A.410 类），偶发接触器吸合异常声。
- **排查步骤**：①测驱动器三相进线电压及瞬间跌落；②检查主回路熔断器（含半熔：阻值增大）；③目视母线电解电容有无鼓包漏液；④核对伺服变压器容量与线径。
- **根本原因**：主回路一相熔芯氧化"半熔"，接触电阻大压降大。
- **处理方案**：三相熔芯同批次更换并力矩紧固；电容老化则返厂更换电容板。
- **预防措施**：熔断器年检测温+目视；驱动器 5 年返厂评估电容。

### 案例 24｜伺服过载/过热
- **现象**：运行中报电机过载/过热（OL / A.910 类），电机外壳烫手。
- **排查步骤**：①驱动器面板看实时负载率（应 <80%）；②手动盘车检查丝杠、导轨是否卡滞；③检查抱闸是否未完全打开（电流异常偏大+低速时更明显）；④检查电机散热片积尘与风扇；⑤校核电机容量与负载惯量比（应 <10）。
- **根本原因**：丝杠润滑干涸摩擦力增大，且抱闸间隙偏小未全脱开。
- **处理方案**：清洗丝杠导轨重新按油脂表润滑；抱闸间隙调整至 0.1～0.3mm 并验证开启电流。
- **预防措施**：负载率纳入日检；按润滑图表保养；抱闸开启反馈进 PLC 互锁。

### 案例 25｜编码器报警
- **现象**：伺服报编码器断线/通讯错误（A.810 / 编码器类代码），时好时坏。
- **排查步骤**：①检查电机端编码器插头是否松动、进油进水氧化；②测编码器电缆通断与屏蔽；③检查编码器线是否与动力线同槽敷设；④用备用线临时跨接验证；⑤交换同型号电机编码器定位坏件。
- **根本原因**：编码器插头被切削液渗入腐蚀，针脚接触不良。
- **处理方案**：更换编码器电缆与插头，螺纹处密封胶+护套，走线独立穿管远离动力线。
- **预防措施**：插头密封纳入点检；编码器线独立金属管敷设。

### 案例 26｜伺服飞车
- **现象**：使能瞬间电机高速飞转，撞限位后急停报警，非常危险。
- **排查步骤**：①检查编码器电池与绝对位置数据有效性；②检查反馈线焊点与屏蔽；③核对驱动器与电机相序/代码匹配；④检查速度/转矩给定模拟量线路有无窜入干扰；⑤检查接地系统。
- **根本原因**：绝对值编码器电池掉电+反馈插头虚焊，速度反馈瞬间丢失导致失控。
- **处理方案**：重焊反馈线、更换电池、重新回零并核对软限位；先低速 JOG 验证方向与反馈后再投自动。
- **预防措施**：编码器电池电压趋势监视、2 年强换；使能前强制低速试运行宏。

### 案例 27｜定位精度超差
- **现象**：机械手重复定位精度由 ±0.05mm 恶化到 ±0.3mm，产品尺寸波动。
- **排查步骤**：①激光干涉仪/球杆仪测定位误差曲线；②检查丝杠背隙、联轴器与胀套是否打滑（做标记线观察）；③核对驱动器增益与前馈参数是否被改动；④检查导轨磨损与爬行；⑤检查编码器联轴器同心度。
- **根本原因**：电机与丝杠间胀套联轴器松动打滑，丢转累积误差。
- **处理方案**：按规定力矩重新紧固胀套（并做防松标记），重新校零点、刷新螺距补偿表。
- **预防措施**：关键轴精度纳入月度测量台账；参数修改必须走变更单+备份。

### 案例 28｜伺服低速抖动异响
- **现象**：低速进给时电机抖动、有啸叫，加工表面出现振纹。
- **排查步骤**：①查看增益、滤波器参数有无改动；②检查机械联接刚性（键、联轴器、轴承座螺栓）；③空载分离电机与机械验证振源；④用驱动器频响功能测机械共振点。
- **根本原因**：丝杠轴承座刚性不足，机械共振点落入速度环带宽内。
- **处理方案**：设置陷波滤波器避开共振频率；加固轴承座/提高联接刚性后重新整定增益。
- **预防措施**：机械改造后必须做频率响应整定；建立参数版本备份库。

### 案例 29｜再生电阻过热烧毁
- **现象**：再生（制动）电阻外壳变色、有焦味，最终烧断开路。
- **排查步骤**：①断电测再生电阻阻值与对地绝缘；②按工况核算回馈功率与电阻占空比是否超配；③检查驱动器"电阻占空比"参数设定；④检查电阻通风与积尘。
- **根本原因**：工艺改为高频往复动作后，回馈能量超出电阻 70% 占空比能力。
- **处理方案**：更换更大功率外置制动电阻并独立风冷；按新工况重设制动参数。
- **预防措施**：工艺节拍变更前核算制动能量；再生电阻温度纳入巡检。

### 案例 30｜使能即报过载且电机不转
- **现象**：伺服一使能即报过载/过转矩，电机纹丝不动。
- **排查步骤**：①断电手动盘车确认机械无卡滞；②测抱闸线圈供电电压与整流器输出；③检查抱闸开启延时参数；④测电机三相电阻平衡；⑤测驱动器 U/V/W 输出电压。
- **根本原因**：抱闸整流器损坏，抱闸未打开，电机带闸堵转报过载。
- **处理方案**：更换抱闸整流器，实测抱闸完全开启后再使能；抱闸开启状态接入 PLC 监控。
- **预防措施**：抱闸整流器纳入备件清单；抱闸开启反馈做使能互锁。

# 第四类：工业通讯故障（案例 31—40）

### 案例 31｜PROFIBUS 从站周期性掉站
- **现象**：某 DP 从站每天掉站 1～2 次，CPU 报 OB86 中断，复位后恢复。
- **排查步骤**：①读 OB86/诊断缓冲区统计掉站时刻与从站号；②测总线 A/B 线对地直流电压（终端电阻 ON、总线空闲时参考：B 线约 +3V、A 线约 +1.5～2V，B 线电位高于 A 线；以现场实测与厂商手册为准）与终端电阻位置（只有首末端 ON）；③检查 DP 头屏蔽层压接；④排查同槽干扰源（变频电缆、焊接设备）；⑤逐段隔离定位故障段。
- **根本原因**：DP 头屏蔽层未压接，且总线与变频器输出电缆并行敷设 50m，干扰叠加。
- **处理方案**：重做全部 DP 头（屏蔽 360° 可靠压接），总线移入独立桥架，远离动力电缆 ≥300mm。
- **预防措施**：通讯线施工规范培训；新增/改动 DP 头后做总线诊断测试。

### 案例 32｜PROFINET 通讯中断
- **现象**：报 PROFINET 通讯中断（RT/设备掉站），设备停机，交换机某口灯灭或不规律闪。
- **排查步骤**：①读 PLC 端口诊断确定断点位置；②检查交换机端口指示；③网线测试仪查通断/线序/长度；④检查 RJ45 水晶头氧化松动；⑤重点检查拖链内网线弯曲疲劳点。
- **根本原因**：拖链内使用普通网线，弯折疲劳断股。
- **处理方案**：更换工业级 PUR 拖链网线，两端重新压接并做通断标记。
- **预防措施**：拖链内必须用高柔性工控网线；交换机预留备用端口做跳接预案。

### 案例 33｜Modbus RTU 通讯超时
- **现象**：上位机循环读取仪表数据，频繁报"超时"，时好时坏。
- **排查步骤**：①检查各从站 A/B 线是否接反、485 公共地是否连接；②核对全部站点波特率/校验位/停止位/站地址一致；③检查总线首末端 120Ω 终端电阻；④计算轮询从站数与响应超时是否匹配；⑤检查总线与动力线距离。
- **根本原因**：后期新增从站未接终端电阻且未做共地，总线信号反射。
- **处理方案**：首末端加装终端电阻，做等电位联结，按从站数重新整定轮询周期与超时。
- **预防措施**：485 网络组态图归档；新增站点走变更单并同步更新组态图。

### 案例 34｜上位机与 PLC 以太网丢包
- **现象**：HMI 数据刷新偶尔卡顿、偶发通讯超时，但设备不停机。
- **排查步骤**：①长时间 ping 统计丢包率与时延抖动；②读交换机端口错误计数（CRC/FCS 错误）；③检查光口收发光功率；④排查 IP 冲突（ping 空闲 IP 应无响应）；⑤用抓包工具统计广播流量占比。
- **根本原因**：办公网电脑私接入生产交换机，广播流量挤占带宽。
- **处理方案**：生产/办公网 VLAN 隔离，交换机端口绑定 MAC、闲置端口 shutdown。
- **预防措施**：生产网络管理制度宣贯+端口安全策略；网络拓扑图归档。

### 案例 35｜总线传输模拟量偶发跳满量程
- **现象**：经总线传输的温度/压力值偶尔瞬间跳到满量程又恢复。
- **排查步骤**：①总线诊断工具抓包统计 CRC 校验错误；②检查总线电缆屏蔽与接地；③检查从站供电电压跌落；④比对跳变时刻与附近大接触器/电磁阀动作时刻的相关性。
- **根本原因**：大电感负载分断尖峰经耦合进入总线，个别报文出错被从站以极限值填充。
- **处理方案**：接触器线圈加 RC 吸收回路、直流线圈加续流二极管；总线重新单端接地；上位程序增加跳变滤波（限速滤波）。
- **预防措施**：大电感负载统一配浪涌吸收器；模拟量跳变逻辑滤波标准化。

### 案例 36｜核心交换机故障整网瘫痪
- **现象**：车间整段网络瘫痪，所有 HMI 黑屏、MES 采集中断。
- **排查步骤**：①看核心交换机电源指示与告警干接点；②分段拔下联口定位广播风暴或环路；③测交换机供电电压与 UPS 输出；④检查机柜温度与风扇；⑤用备用交换机替换验证（导入配置备份）。
- **根本原因**：核心交换机电源模块电容老化宕机（已连续运行 6 年）。
- **处理方案**：更换电源模块，恢复最新配置备份；网络改造为环形冗余（MRP/STP），核心层双电源。
- **预防措施**：交换机配置每月备份；关键网络设备 5～6 年预防性更换（已列入《年度保养计划》周期表第 16 项）。

### 案例 37｜光纤链路告警时通时断
- **现象**：跨车间光纤链路周期性告警，雨天加重。
- **排查步骤**：①光功率计测两端收光功率并与竣工值比对（衰耗增量 >3dB 即异常）；②检查法兰/尾纤端面清洁（端面检测仪/放大镜）；③检查走线弯曲半径是否过小（应 ≥30mm）；④打开熔接盒检查熔点与余纤盘绕。
- **根本原因**：尾纤端面积尘+局部弯曲半径过小，附加衰耗逼近接收灵敏度。
- **处理方案**：无尘签+无水乙醇清洁端面，重新盘纤并固定弯曲半径，重测光功率留档。
- **预防措施**：光功率半年检测并记录趋势；法兰盒加装防尘帽与干燥剂。

### 案例 38｜RS485 中继器损坏远端失联
- **现象**：总线上远端 4 台仪表全部失联，近端从站通信正常。
- **排查步骤**：①测中继器供电电压；②旁路（短接）中继器试验远端是否恢复；③测中继器两侧总线电平；④检查室外立杆线路与外壳有无雷击痕迹。
- **根本原因**：室外架空线路感应雷击，浪涌损坏中继器。
- **处理方案**：更换中继器，室外线路两端加装信号 SPD 防雷器，做好等电位连接与接地。
- **预防措施**：室外 485 线路必须装 SPD；每年雷雨季前检测接地电阻。

### 案例 39｜网络广播风暴致采集中断
- **现象**：MES 数据采集中断，交换机所有端口灯齐闪，网络严重卡顿。
- **排查步骤**：①端口镜像抓包统计广播包占比（正常 <20%）；②按二分法逐段拔线定位环路点；③检查现场是否私接傻瓜交换机；④核对各交换机生成树（STP/RSTP）配置。
- **根本原因**：操作工私接小型交换机并将两根网线同时插入，形成物理环路引发广播风暴。
- **处理方案**：拆除私接设备；全部交换机启用 STP + 广播风暴抑制（如 10%）；端口绑定。
- **预防措施**：网络接入管理制度与培训；交换机闲置端口默认 shutdown。

### 案例 40｜新增远程 IO 站无法组态
- **现象**：新加装 ET200/远程 IO 站始终报"找不到设备"，无法下载组态。
- **排查步骤**：①核对 GSDML/GSD 文件版本与工程库一致；②核对设备名称（Device Name）/IP 与组态完全一致（大小写敏感）；③用组态工具搜索在线设备读实际名称；④检查从站自身供电与拨码地址；⑤直连笔记本与从站交叉验证。
- **根本原因**：现场设备未赋名（出厂默认名）且工程 GSD 版本旧于设备固件。
- **处理方案**：用调试工具对设备赋名，更新 GSDML 后重新组态下载并保存归档。
- **预防措施**：建立 IO 站命名规范（区域-产线-站号）；变更单含"组态一致性核对"必检项。

# 第五类：传感器故障（案例 41—50）

### 案例 41｜接近开关误动作
- **现象**：无金属物经过，接近开关仍偶发导通，PLC 收到假信号。
- **排查步骤**：①统计误动作与振动/变频启动时刻相关性；②清理感应面吸附的金属切削屑；③检查检测距离是否调至临界（接近额定 Sn）；④检查屏蔽与接地；⑤更换同型号验证。
- **根本原因**：机加工切削屑吸附感应面，且安装距离过近处于临界检测区。
- **处理方案**：清理感应面，重调检测距离至 0.7Sn 以内，改用齐平式/防焊型接近开关。
- **预防措施**：机加工线传感器纳入周清洁；检测距离写入点检表。

### 案例 42｜光电开关漏检
- **现象**：工件通过但光电开关偶发无输出，造成漏计数/漏检测。
- **排查步骤**：①清洁发射/接收透镜；②用对光卡纸检查光轴对准；③检查灵敏度电位器是否被误调至临界；④核对工件表面颜色/反光率变化（换料后）；⑤检查背景物反光干扰。
- **根本原因**：粉尘糊住透镜+灵敏度处于临界值，浅色反光工件时偶发不切换。
- **处理方案**：清洁透镜并重新标定灵敏度（动作边界的 1.5 倍），加装防尘罩与压缩空气吹扫。
- **预防措施**：透镜纳入日检清洁；换产品型号时重新标定光电参数。

### 案例 43｜增量编码器丢脉冲
- **现象**：定位累计偏差越来越大，回零后正常，运行越久偏得越多。
- **排查步骤**：①示波器看 A/B/Z 波形幅值（应 ≈24V 方波）与 90° 相位差；②检查屏蔽层接地与干扰源；③检查编码器联轴器/胀紧套是否打滑；④核对高速计数器滤波/抗干扰设置；⑤测编码器供电纹波。
- **根本原因**：干扰毛刺被高速计数器计入，多计脉冲造成累计误差。
- **处理方案**：编码器线改双绞屏蔽并单端接地，使能计数器硬件滤波，更换老化电缆。
- **预防措施**：编码器电缆与动力电缆分离敷设；供电纹波 <5%；每月做定位精度比对。

### 案例 44｜绝对值编码器数据跳变
- **现象**：多圈绝对位置数据偶发跳变，报"位置非法"。
- **排查步骤**：①读编码器电池告警位；②测电池电压；③排查传输干扰（同丢脉冲方法）；④核对多圈圈数是否超量程溢出。
- **根本原因**：编码器电池电压临界，掉电时多圈数据部分丢失。
- **处理方案**：更换电池、重新校零点与圈数；建立全厂绝对值编码器电池台账。
- **预防措施**：绝对值编码器电池 2 年强制更换；电压纳入趋势监视。

### 案例 45｜温度显示异常
- **现象**：温度显示 -30℃、满量程或乱码跳变。
- **排查步骤**：①区分传感器/线路/模块：标准电阻法——在模块端子接入 100.00Ω 标准电阻应显示 0℃（Pt100 按 IEC 60751，或用过程校验仪注入对应电阻）；将通道输入三线短接后应显示**量程下限或短路/欠量程报警**，以此区分断线（显示上限/断线报警）与短路；注意：**短接后显室温附近是热电偶回路的判法，不适用于热电阻（PT100）**；②万用表测 PT100 阻值与温度对照（0℃=100Ω，每 +1℃ 约 +0.385Ω）；③检查三线制补偿线三根是否都接牢；④热电偶回路检查补偿导线型号极性（热电偶短接即构成测温结点、显示室温附近，该判法仅适用于热电偶回路）。
- **根本原因**：三线制补偿线中一根端子松动，桥路失衡读数飘负。
- **处理方案**：紧固端子；用标准电阻/校验仪对显示通道校验并记录。
- **预防措施**：端子紧固纳入周检；温度仪表年度校验。

### 案例 46｜压力变送器零点漂移
- **现象**：管路已泄压排空，变送器仍显示 0.4MPa 不回零。
- **排查步骤**：①泄压后对空罐读零点；②毫安表串入回路测输出（空载应 4.00mA）；③检查取样管是否堵塞、截止阀状态；④检查安装姿态与膜片有无变形损伤。
- **根本原因**：膜片曾受水击超压冲击微量变形+取样管杂质。
- **处理方案**：更换变送器并送检调校；取样管定期排污，泵出口加装缓冲器。
- **预防措施**：压力表按半年周期校验；超压工况（水锤）记录并评估。

### 案例 47｜液位开关误报水泵频繁启停
- **现象**：水池液位正常但报"低液位"，水泵频繁启停。
- **排查步骤**：①就地磁翻板液位计比对实际液位；②检查浮球开关摆动是否卡滞；③剖开电缆检查进水；④检查控制逻辑液位延时参数；⑤检查液面涡流/泡沫影响。
- **根本原因**：浮球被水垢油泥粘滞卡在低位+电缆入口密封失效进水。
- **处理方案**：清洗除垢浮球、重做电缆密封；控制逻辑加 5s 防抖延时；关键水池改双开关冗余。
- **预防措施**：液位开关季度检查清洗；水泵启停逻辑统一加延时。

### 案例 48｜安全光幕误触发停机
- **现象**：无人遮光，安全光幕偶发报错使设备急停。
- **排查步骤**：①读光幕自诊断代码（对准/污染/串扰）；②清洁发射/接收器镜面；③检查支架振动与对准角度；④检查光幕对面/侧面新增反光面（不锈钢护罩、镜面板）；⑤检查屏蔽线与接地。
- **根本原因**：现场新装不锈钢防溅护罩形成强反射，光束串扰误判遮挡。
- **处理方案**：调整光幕角度避开反射路径、加装遮光板，重新对光并做遮挡试验验证。
- **预防措施**：光幕周围工艺变更需做安全评估；镜面纳入周清洁；保留遮挡试验记录。

### 案例 49｜称重传感器读数漂移
- **现象**：秤台空载显示每天漂移数公斤，去皮后缓慢变化。
- **排查步骤**：①标准砝码做四角误差与线性检定；②检查秤台限位螺栓是否顶死、有无物料卡在秤台与框架间；③检查传感器电缆与接线盒进水受潮；④测激励电压与各传感器 mV 输出；⑤检查接地与静电。
- **根本原因**：秤台限位螺栓被物料顶死+一只传感器电缆破损受潮。
- **处理方案**：调整限位间隙 0.2～0.3mm，更换受潮传感器，重做接头密封与热缩，重新标定。
- **预防措施**：称重系统每日砝码点检；接线盒干燥剂每季更换；秤台周边卫生纳入岗位规程。

### 案例 50｜限位开关不复位
- **现象**：机械回原点后原点开关仍保持亮，系统报"回原点失败"。
- **排查步骤**：①手动按动摆杆用万用表测通断；②检查摆杆/滚轮是否被油泥粘死、扭簧疲劳断裂；③检查触点组件有无熔焊；④检查防水圈老化与内部进油；⑤测量动作位置是否偏移。
- **根本原因**：摆杆转轴被切削液油泥粘死，动作后不复位。
- **处理方案**：清洗或整体更换限位开关，加装防护罩避免油泥直喷，重校动作位置。
- **预防措施**：原点/限位开关月度手动动作试验；油污区域选用密封型开关。
