# 新员工电气安全培训大纲（4 课时）

> **培训对象**：新入职电气技术员、电工、机电设备操作工（含转岗员工）。
> **培训时长**：4 课时 × 45 分钟，共 180 分钟，建议分两天完成（第 1～2 课时、第 3～4 课时）。
> **培训方式**：PPT 讲授 + 视频案例 + 模拟人实操 + 角色演练 + 结业考核。
> **考核标准**：笔试（30 题，≥80 分合格）+ 实操（验电/挂票流程/CPR 三项逐项合格）；双合格方可授权独立上岗，未通过者一周内补考一次。
> **培训纪律**：手机静音、迟到超过 10 分钟取消本次资格；实操环节必须听从讲师指令。

---

## 第 1 课时：电气安全基础与危险识别（45 分钟）

**教学目标**：了解电流对人体的伤害机理，记住安全电压等级与本厂供电结构，能识别常见电气危险源。

**时长分配**：讲授 35 分钟 + 互动问答 10 分钟。

| 页码 | PPT 要点 |
|---|---|
| P1 | 封面：课程名称、讲师、课时安排、考核说明 |
| P2 | 培训目标与纪律：4 课时地图（基础→急救→两票→点检实务） |
| P3 | 为什么要学：近年全国电气事故数据 + 1 个真实触电死亡案例还原 |
| P4 | 电流对人体的效应：感知电流约 1mA；摆脱电流约 10mA；致命电流约 30mA（室颤） |
| P5 | 影响伤害程度的四因素：电流大小、持续时间、电流路径（手到手/手到脚）、频率 |
| P6 | 安全电压等级：42V / 36V / 24V / 12V 及适用场所；本厂电压等级：10kV 进线→400V→380V/220V→DC24V |
| P7 | 一张图看懂本厂供配电：变压器→低压配电室→车间配电柜→控制柜→设备 |
| P8 | 常见电气危险源识别：裸露端子、破损电缆、湿手操作、带电清灰、无证动电、私接插线板 |
| P9 | 电弧危害专讲：电弧温度可达数千度，"看不见的烧伤"——断路器面板操作站位 |
| P10 | 电气安全标识：禁止类（禁止合闸）、警告类（当心触电）、指令类（必须戴绝缘手套）识图 |
| P11 | 法规与标准：《安全生产法》相关条款、GB 26860 电力安全工作规程、本厂"电气十条红线"逐条解读 |
| P12 | 小结 + 随堂问答（5 题抢答）：本厂安全电压？哪些行为属于红线？ |

**互动设计**：让学员指出一张车间现场照片中的 5 处电气隐患（答案：拖地插线板、柜门敞开、电缆压在通道、灭火器缺失、未挂警示牌）。

## 第 2 课时：触电急救与个人防护（45 分钟）

**教学目标**：掌握脱离电源方法与心肺复苏流程，会检查、正确穿戴电工防护用品。

**时长分配**：讲授 25 分钟 + CPR 模拟人实操 15 分钟 + 随堂测 5 分钟。

| 页码 | PPT 要点 |
|---|---|
| P1 | 复习提问：致命电流是多少毫安？（衔接上节课） |
| P2 | 触电急救"黄金 4 分钟"：每延迟 1 分钟存活率下降约 10% |
| P3 | 脱离电源：低压——拉闸、拔插头、干燥木棍挑开线，严禁徒手拉拽；高压——保持安全距离（10kV ≥0.7m），通知电工断电 |
| P4 | 心肺复苏 CPR 六步：评估环境→判断意识呼吸→呼救拨打 120→胸外按压（位置：两乳头连线中点，深度 5～6cm，频率 100～120 次/分）→开放气道→人工呼吸 |
| P5 | 按压/吹气比 30:2，坚持到专业人员接手；只按压式 CPR 也有效 |
| P6 | AED 使用四步：开机→贴片（右锁骨下+左腋下）→分析心律（不接触患者）→电击/继续按压 |
| P7 | 电烧伤现场处理：不撕粘连衣物、冷水冲、清洁敷料覆盖、不涂牙膏酱油 |
| P8 | 电工 PPE 清单：绝缘手套（耐压等级）、绝缘鞋、护目镜（防电弧）、电弧防护服、安全帽 |
| P9 | 绝缘手套使用前检查：外观无破损发粘、充气检漏法演示、6 个月耐压试验标签识别 |
| P10 | 随身仪表规范：验电笔使用（先在带电体确认良好）；万用表测电压档位选择；钳形表不断线测流 |
| P11 | 临时用电安全：一机一闸一漏保、电缆架空不拖地、雨天室外禁用 |
| P12 | 小结 + 随堂测 5 题（CPR 深度/频率、绝缘手套检查等） |

**实操安排**：分组在 CPR 模拟人上每人完成 2 个循环（30:2），讲师逐个纠正按压深度与频率。

## 第 3 课时：两票三制与停送电/检修作业（45 分钟）

**教学目标**：理解"两票三制"体系，能按流程正确办理、执行停送电操作票和检修作业票，掌握挂牌上锁（LOTO）。

**时长分配**：讲授 30 分钟 + 操作票角色演练 12 分钟 + 小结 3 分钟。

| 页码 | PPT 要点 |
|---|---|
| P1 | 案例导入：某厂走错间隔带电挂地线事故——"每一次违章都可能是最后一次" |
| P2 | 两票三制：操作票、工作票；交接班制、巡回检查制、设备定期试验轮换制 |
| P3 | 停送电操作票全流程：用电申请→填票→审核（两级）→模拟预演→现场操作（监护唱票）→复查汇报 |
| P4 | 操作票填写规范：设备双重编号（名称+编号）、逐项填写、不得涂改、每页须审核签字 |
| P5 | 倒闸操作"六关"：接令关、核对关、模拟关、监护关、唱票复诵关、检查关 |
| P6 | 挂牌上锁 LOTO：谁上锁谁摘锁、一人一锁一钥匙、个人锁+集体锁双重管理、钥匙遗失处理 |
| P7 | 停电作业"五步法"：停电→验电→放电→挂接地线（先接接地端后接导体端）→悬挂标示牌和装设遮栏 |
| P8 | 检修作业票办理：申请（工作内容/时间/人员）→风险分析（JSA）→安全措施逐条确认→许可签字→作业→终结验收 |
| P9 | 恢复送电：拆除地线（与挂装相反顺序）→清点人员工具→逐级拆牌解锁→送电汇报；严禁"约时停送电" |
| P10 | 角色演练说明：分组抽签扮演操作人/监护人/值班负责人，走完一张真实操作票（3# 输送线电机回路停电） |
| P11 | 典型违章讨论：3 个场景判断对错（口头停送电/代签票/未验电作业） |
| P12 | 小结：两票是保命票；考核重点预告 |

**角色演练**：讲师预设 2 处"埋雷"（票面设备编号错误、漏验电步骤），观察学员能否发现，纳入平时分。

## 第 4 课时：点检实务与故障上报（45 分钟）

**教学目标**：会使用日点检表完成五大类设备点检，掌握异常上报流程与故障库检索方法。

**时长分配**：讲授 25 分钟 + 场景演练 12 分钟 + 结业考核说明 8 分钟。

| 页码 | PPT 要点 |
|---|---|
| P1 | 点检的意义：90% 的故障有前兆——点检就是把故障消灭在萌芽（**教学示例数据**：模拟工厂点检上线后故障率下降 40%，非真实统计，使用时替换为本厂实测数据） |
| P2 | 点检五感法：视（颜色/液位/指示灯）、听（异响节奏）、触（温度/振动）、嗅（焦味/臭氧味）、问（操作工） |
| P3 | 日点检表使用：判定符号（√/×/△）、正常范围阈值怎么读、异常记录栏填写规范 |
| P4 | 五大类设备点检要点速览：配电柜（电压/温度）、电机（电流/温升/振动）、PLC 柜（状态灯/柜温）、伺服（负载率/报警码）、传感器（信号/清洁） |
| P5 | 点检仪表四件套：钳形电流表、红外测温枪、振动笔、兆欧表——操作要领与读数判断（现场传看演示） |
| P6 | 异常上报流程图：发现→初步判断（安全吗？）→紧急异常立即上报（四要素）→MES 提交工单→跟进闭环 |
| P7 | 故障库检索实训：按"设备类型+现象关键词"检索案例；五段式结构的阅读方法 |
| P8 | 维修现场配合须知：不停机不伸手、运转部位保持距离、听从监护人指挥、不做超越授权的作业 |
| P9 | 场景演练（3 选 1 抽签）：A 电机外壳烫手+焦味怎么办？B PLC 柜 SF 灯亮怎么办？C 伺服报过流怎么办？ |
| P10 | 结业考核安排：笔试范围（4 课时要点，30 题）、实操三项（验电、办票流程口述、CPR）、评分标准 |
| P11 | 课程知识地图回顾：基础→防护→两票→点检，一条主线"不伤害自己、不伤害他人、不被他人伤害" |
| P12 | 安全承诺书签署 + 讲师寄语 |

**场景演练评分点**：是否先保安全（停机/上报）→ 是否用对流程（工单/电话）→ 是否会查故障库 → 表述四要素是否完整。
