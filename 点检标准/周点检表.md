# 电气设备周点检表

> **适用范围**：全厂低压配电系统、电机回路、控制柜、现场仪表。
> **点检频次**：每周一次（建议周五白班执行，避开生产高峰），需办理检修作业票、部分项目需停机停电后执行。
> **安全要求**：凡涉及接触带电部件的项目（端子紧固、兆欧表测试），必须**停电、验电、挂牌上锁**后进行；测试完毕必须拆接地线、清点工具、撤牌送电。
> **判定规则**：每项记录实测值；实测值超标准值即为异常，开维修工单处理。

## 周点检项目（12 项）

| 1 | **接地电阻测量** | 断开设备电源，用接地电阻测试仪（三极法）测 PE 干线及重点设备接地端子；雨季前必测 | 保护接地电阻 ≤4Ω；TN-S 系统 PE 与 N 之间绝缘良好 | 每周抽测 20% 设备，轮换覆盖 |  | √/× |
| 2 | **绝缘电阻测试（低压回路）** | 停电验电后，用 500V 兆欧表（新型数字兆欧表）测电机绕组、电缆相间及相对地绝缘，摇测 1 分钟读数，测后放电 | 运行中电机绕组 ≥0.5MΩ；电缆 ≥1MΩ；控制回路 ≥0.5MΩ | 每周抽测（按轮换表） |  | √/× |
| 3 | **散热风扇与滤网清洁** | 断电后拆下柜顶风扇及滤网，压缩空气（干燥，≤0.3MPa）吹扫或清水冲洗晾干；风扇轴承注油（可注型） | 滤网透光无堵塞积黑；风扇通电试转无异响、无卡滞 | 每周（粉尘车间每 3 天） |  | √/× |
| 4 | **端子与紧固件检查** | 停电验电挂牌后，用力矩扳手按力矩表复紧主回路端子（8.8 级钢制螺栓参考：M8≈20～25N·m、M10≈40～48N·m、M12≈70～80N·m，性能等级按 GB/T 3098.1；黄铜/小规格接线端子及元器件自带端子以柜内力矩标签或厂商说明书为准，通常低于上述值）；检查有无氧化发黑 | 力矩达标；端子无氧化变色、无烧蚀痕迹；弹簧垫圈压平 | 每周抽检 30% 柜，轮换覆盖 |  | √/× |
| 5 | **配电柜除尘** | 断电后用干燥压缩空气（≤0.3MPa）自上而下吹扫柜内粉尘，吸尘器配合，严禁吹向 PLC 模块插槽（先遮护） | 柜内、元器件表面、母线槽无明显积尘；无金属异物 | 每周（重点变频器柜） |  | √/× |

| 7 | **UPS / 直流电源检查** | 查看 UPS 面板自检数据：输入/输出电压、负载率、电池自检结果；记录旁路指示 | 输出 220V ±3%；负载率 ≤70%；电池自检通过、无更换告警 | 每周 |  | √/× |

## 周点检轮换说明

1. **接地电阻与绝缘测试**实行轮换覆盖制：将全厂设备分为 5 组，每周抽测 1 组，保证每月全量覆盖一轮；雨季（6～8 月）增加配电室电缆沟湿度检查。
2. **端子紧固**重点覆盖上周出现过高热（红外温差 >10K）的回路。
3. 测试仪器（兆欧表、接地电阻仪、测温枪）每月自检一次，兆欧表开路试验指针/读数应达 ∞。
