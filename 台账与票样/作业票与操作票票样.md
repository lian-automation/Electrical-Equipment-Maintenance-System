# 检修作业票 / 停送电操作票 票样

> **用途**：配套《电气设备管理制度汇编》第二、三章使用，演示票面要素与填写方法；制度条款以制度汇编为准。
> **数据性质**：票样模板 + **示例填写（虚构）**；使用时按本厂编号规则与实际作业填写。

---

## 样式一：检修作业票（二类票，示例填写）

| 栏目 | 内容 |
|---|---|
| 票号 | JZ-2025-0418（示例） |
| 票种分类 | □ 一类（高压设备检修/带电作业/动火，设备部长批准）　☑ 二类（低压配电柜停电检修/控制系统检修，设备工程师批准）　□ 三类（不停电检查/清洁/润滑，班组长批准） |
| 工作内容 | 3# 输送线主驱动电机（YE3-132M-4）检修更换（模拟演练作业） |
| 工作地点 | 二车间主输送线 3# 驱动站 |
| 计划作业时间 | 2025-04-18 14:15 — 15:45（示例） |
| 工作负责人 | 李工（电工，示例） |
| 工作班成员 | 电工 2 人 + 监护人 1 人（共 3 人） |
| 安全措施（逐条确认，不得笼统写"注意安全"） | ① 断开 3# 电机回路上一级电源开关 ☑　② 验电（合格验电器逐相验电，先在带电体上确证良好）☑　③ 放电 ☑　④ 装设接地线（先接接地端、后接导体端）☑　⑤ 悬挂"禁止合闸，有人工作"标示牌并上锁 ☑　⑥ 设置警戒区/遮栏 ☑ |
| 关联操作票号 | CS-2025-0418（见样式二） |
| 运行值班许可 | 双方现场确认安全措施后签字：工作负责人____　运行值班____（示例：值班长 钱工） |
| 延期 | 无（如需：提前 30 分钟申请，批准人票面签注；一张票最多延期一次） |
| 终结 | 现场清理 ☑　人员工具清点 ☑　临时接地线/遮栏拆除 ☑　验收签字：工作负责人____　运行值班____　终结时间____ |

> 票面要求（制度第二章）：一票对应一个工作地点、一组工作人员、一个作业时段；一处变更须重新办票；已终结票由设备部统一编号归档，保存 3 年。

## 样式二：停送电操作票（示例填写）

| 栏目 | 内容 |
|---|---|
| 票号 | CS-2025-0418（示例） |
| 操作任务 | 3# 输送线主回路停电（配合 3# 电机检修更换） |
| 操作设备（双重名称编号） | 2# 配电室低压柜「3# 输送线回路 403」（EJ2-A01-F-003 上级回路，示例） |
| 操作人 | 张工（示例） |
| 监护人 | 赵工（示例） |
| 值班负责人批准 | 钱工（示例） |
| 关联检修作业票 | JZ-2025-0418（见样式一） |

**操作顺序（逐项执行"唱票—复诵—核对设备编号—操作—打勾"）**：

| 序号 | 操作项目 | 执行 |
|---|---|---|
| 1 | 检查 3# 输送线已停机、负荷侧无输出 | √ |
| 2 | 断开 403 回路断路器 QA403 | √ |
| 3 | 检查 QA403 确在断开位置 | √ |
| 4 | 断开 403 回路负荷侧隔离开关 QS403 | √ |
| 5 | 在 403 回路负荷侧验电（合格验电器，先在带电体上确证良好，逐相验电）确无电压 | √ |
| 6 | 放电 | √ |
| 7 | 装设接地线：先接接地端、后接导体端 | √ |
| 8 | 悬挂"禁止合闸，有人工作"标示牌并上锁（一人一锁一钥匙） | √ |

| 栏目 | 内容 |
|---|---|
| 操作完成时间 | 14:20（示例） |
| 执行情况 | 监护人全程唱票、操作人复诵并手指口述核对设备编号，逐项打勾；无疑问项、无跳项 |
| 备注 | ① 恢复送电按本票反向顺序另行开票执行，送电前必须确认作业票已终结、接地线已全部拆除、人员已撤离；② 操作中发生疑问立即停止，查明原因前严禁继续操作；③ **严禁约时停送电**；④ 票面不得涂改，写错作废重填；一张票对应一个操作任务 |

> 票面要求（制度第三章）：操作票经操作人自审、监护人复审、值班负责人批准三级审核签字；操作完成后加盖"已执行"章，按月装订归档保存 1 年。
